# Tracking Trick

Windows 트레이 기반 자동 클릭 도구입니다. 마우스가 설정한 시간 동안 움직이지 않으면 현재 커서 위치를 좌클릭하며, 설정한 지속 시간이 끝나면 클릭을 멈춥니다. 사용자가 마우스를 움직이면 진행 중인 클릭을 즉시 중단하고 새 유휴 대기 주기를 시작합니다.

## 실행

Windows와 .NET 9 SDK가 필요합니다.

```powershell
dotnet run
```

시작하면 창은 트레이 아이콘으로 자동 숨김 처리됩니다. 트레이 아이콘을 더블클릭하거나 메뉴의 **Open**을 누르면 설정 창을 열 수 있습니다.

## 설정

- 유휴 시간: 클릭을 시작하기 전 마우스가 정지해야 하는 시간
- 클릭 간격: 최소~최대 사이에서 매 클릭마다 무작위로 선택되는 간격
- 클릭 지속 시간: 자동 클릭이 실행되는 총 시간
- 활성화 시 바로 시작: 켜는 즉시 클릭 주기를 시작
- 자동 클릭 활성화: 프로그램을 종료하지 않고 모든 자동 동작을 켜거나 끔

창의 닫기 버튼은 프로그램을 종료하지 않고 트레이로 숨깁니다. 트레이 메뉴의 **종료**만 앱을 완전히 종료합니다.
